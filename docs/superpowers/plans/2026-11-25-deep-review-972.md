  `docker run -d` gives `nc -l -p 8001` a /dev/null stdin; busybox nc closes the connection at once, so
  the "frozen" `voice` is a closed one. In CI the three frozen Dials took 0.29 s in all (at least 2 s
  each with `connection_timeout=2000` against a silent peer). Local proof: a client against the check's
  server returns at once; against `sleep 600 | nc -l -p 8001` it is held until its 6 s timeout. So a
