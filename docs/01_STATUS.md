## Versioning of This File

Own, semantic version `MAJOR.MINOR.PATCH`, independent of the `CLAUDE.md` bundle version and of README gate version (`docs/15_README_STRATEGY.md`) — README versions the product outward, this file versions itself inward:

| Bump | Trigger | Example |
|---|---|---|
| **MAJOR** | Gate passed / stage transition / architecture decision (E-Nr) flipped | G0 passed → stage 1 begins |
| **MINOR** | Decision made (D-Nr answered), new work package result changes "What's next" | D1 vendor chosen |
| **PATCH** | pure status housekeeping: task check, new assumption, new/resolved blocker | T-0.1 to done |

**Auto-update:** `python scripts/status_bump.py <patch|minor|major> "<one-line change>"` sets date, version, and changelog line automatically. Called by `/done`, `/task`, `/handover` (see `.claude/commands/`) — by hand only if needed. Extra safety net: CI (`.github/workflows/ci.yml`) fails if `docs/07_WORKPACKAGES.md` changes but `docs/01_STATUS.md` stays unchanged in the same diff.
