3. So läuft jede Zeile ab

  1. Leitung schreibt im Chat Zeile 1 start (mit der Nummer der Zeile).
  2. Claude bereitet den Ausfall vor und antwortet Zeile 1: jetzt anrufen. Vorher nicht anrufen.
  3. Leitung sagt „jetzt“, Anrufer/in drückt auf Anrufen. Leitung schreibt die Uhrzeit mit Sekunden in „Anruf gestartet“.
  4. Sobald Telefon B klingelt: Uhrzeit mit Sekunden in „Telefon B klingelt“.
  5. Die Zeile so zu Ende führen, wie sie im Kasten steht. Dann beide auflegen.
  6. Leitung schreibt Zeile 1 fertig, gern mit einem Satz dazu, was auffiel.
  7. Claude schaltet den Ausfall wieder aus, nennt die Zeiten aus dem Protokoll und antwortet Leitung bereit. Erst dann die nächste Zeile.

Klingelt Telefon B nach 60 Sekunden nicht: auflegen, „kein Klingeln“ eintragen, Zeile 1 fertig, kein Klingeln schreiben. Das ist ein Ergebnis, kein Fehler von euch.

Sekunden = „Telefon B klingelt“ minus „Anruf gestartet“ (in Zeile 2 minus „Absturz“). Claude rechnet aus dem Protokoll der Anlage gegen; beide Werte bleiben auf dem Bogen.
