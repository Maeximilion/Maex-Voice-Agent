### [P1] Core allergen sentence replaces the model's only when the model set the flag
Verdict: CONFIRMED (P1)
Evidence: Both probe tests are red through `run()`, the real loop entry point. My own probe makes it worse. Turn 1 is "Ich habe eine Erdnussallergie.", turn 2 is "Ist in der 13 Erdnuss?", and the model answers with no lookup: "Nein, in der 13 ist keine Erdnuss." The guest hears that sentence unchanged (state.allergy_talk is True). The same happens with "Ich habe eine Sojaallergie." followed by "Ist in der 23 Soja?", where the model says "Die 23 enthält nur Gluten." and the guest hears it. The guard misses this because `unread_allergy_question` (guards.py:668) reads only the current `user_text` through `asks_about_allergies` (escalation.py:224), and that function needs an allergy word in the same text. The replacement code (loop.py:628, :842-847) only runs on a `SAY_ALLERGENS_LEAD` sentence, which exists only when the lookup was flagged.
Mitigation found: the prompt says "Allergene nur aus `say`" (prompts/tools_v3.md:35, system_v3.md:16). That is the model's cooperation, which hard rule 1 says is not enough. The same-sentence case is guarded: "Ich habe eine Erdnussallergie. Ist in der 13 Erdnuss?" goes to the team (my probe, green).
Not a bug: the flag itself is the model's call by contract (docs/04:339, "nur der Agent weiß, ob der Gast nach Allergenen gefragt hat"). So the fix should not force the flag on every question that names an allergen.
Fix: there are two parts. (1) Extend `unread_allergy_question` to fire when the call already speaks of allergies (`state.allergy_talk` or `state.allergy_said`) and the guest's sentence is a question that names an allergen, not only on `asks_about_allergies(user_text)`. (2) In a turn with a successful `get_item_details` whose `allergens.known` is True, a final say that names an allergen (read after `without_menu_names`) gets the core sentence built from `result.data`, whatever the flag. · Test: the two reviewer probe tests, my two cross-turn tests, and the existing `test_a_sentence_without_a_lookup_in_the_turn_is_left_alone` staying green. · Needs Maxi: no (plain enforcement of rule 1).
